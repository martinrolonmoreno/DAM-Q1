A comprehensive collection of projects, exercises, and logic diagrams completed during my first quarter as a **Multiplatform App Development (DAM)** student at *Universidad Francisco de Vitoria*. 

This repository serves as a log of my foundational learning in programming logic, object-oriented programming (OOP), and database management.

---

## 🗂️ Repository Structure

Here is a breakdown of what you can find inside:

* **`📁 Programas/`**: The core of the repository. Contains Java source code for various exercises, including my latest work with Object Arrays, control structures, and basic OOP principles.
* **`📁 DataBases/`**: SQL scripts, database schemas, and queries to practice relational database fundamentals.
* **`📁 DiagramasFlujo/`**: Flowcharts and logic diagrams used to plan and structure algorithms before writing the actual code.
